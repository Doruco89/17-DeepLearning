4.  주요 결과 요약
--------------------------------------------------------------------------------

  평가지표
    다수 클래스만 답하는 모델의 정확도가 0.3398, macro-F1은 0.0423이다.
    약 8배 차이다. 클래스 불균형(clothes 34.3%) 때문에 정확도는 소수
    클래스 실패를 가린다. 그래서 macro-F1을 주 지표로 삼았다.

  데이터 정제
    완전 동일 중복 16장, 라벨 충돌 6장, 애매·비사진 9장을 제외하고
    46장의 라벨을 정정했다. 원본 파일은 옮기거나 지우지 않고 manifest
    테이블로 관리했다. 근접 중복 25그룹은 삭제 대신 같은 split에 배치해
    데이터 누수를 막았다.

  가설검정
    유리 3종 색상 분포 차이는 순열검정으로 기각했다(p = 0.0002).
    이것이 증강에서 hue를 건드리지 않은 정량적 근거다.
    임계값 조정은 test 예측을 한 장도 바꾸지 못했다. 검증셋에서 골랐기
    때문에 이 사실을 확인할 수 있었다. 통하지 않는다는 확인도 결과로
    보고한다.

  운영 관점
    확신도 0.53 미만인 0.3%(8장)만 사람이 확인하면 나머지는 98.8%
    정확도로 자동 분류된다.
