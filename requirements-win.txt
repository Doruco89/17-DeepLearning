#   1) uv pip install numpy==1.26.4
#   2) uv pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision torchaudio
#   3) uv pip install -r requirements-win.txt

# [Windows 관련 주의사항]
#   - PyTorch: PyPI 의 기본 win_amd64 휠은 CPU 전용입니다.
#     이 PC 의 RTX 5060(Blackwell, sm_120)은 CUDA 12.8 이상 빌드가 필요하므로
#     반드시 cu128 인덱스에서 설치해야 GPU 가속이 동작합니다. (macOS 의 MPS 대체)
#   - TensorFlow: Windows 네이티브는 2.11 부터 GPU 미지원이라 tensorflow-intel(CPU) 로 설치됩니다.
#     1·2장 비교 예제용이므로 문제 없습니다.
#   - librosa/soundfile: Windows 에서는 soundfile 휠에 libsndfile 이 포함되어 별도 설치가 불필요합니다.
#     단, mp3 등 일부 포맷 로딩 시 ffmpeg 가 필요할 수 있습니다. (winget install ffmpeg)
